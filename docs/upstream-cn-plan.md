# 上游 v0.3.0 汉化（A 方案）实施笔记

基线：`b0c705f`（上游 v0.3.0）。分支 `cn-0.3`。版本从 `v0.3a` 起，按字母递增。

## 探测结果（2026-11-07）

用纯净上游构建 + 游戏原包 SD，把 `config.ini` 设为 `[Screen] Language="13"`（schinese）：

- 标题 logo 仍是英文，`请按开始键` 整行不显示（空白）。
- 原因：data.win 自带字体没有 CJK 字形；上游没有实现 `font_replace`，
  `lang/*.ttf` 不会被加载。游戏自带的 `schinese.ini`、中文标题图、7 张中文 headers
  都在，但文字层缺字形。

## 结论

A 方案（运行时解析游戏自带 CJK TTF、抗锯齿光栅化）需要补齐三块：

1. 渲染器：运行时字体图集纹理 + 一个可被字体引用的 TPAG 页，以及上传/失效接口。
2. 字体层：`font_replace` 实现——stb_truetype 取字形、度量、装进 Font 结构；
   处理字号、粗斜体、缺字回退。
3. 排版：CJK 无空格换行、宽度度量一致、暂停页 320 下的文本容器。

## 0.3a 范围（第一版）

- 只做“中文能正确显示”：标题、存档、暂停四页、HUD、扫描横幅。
- 不改上游的暂停/金手指/传送/灯光；不搬状态栏、底图、画面模式选项。
- 字体用游戏自带 16 MB CJK TTF，抗锯齿，不引入点阵资产。
- 默认语言中文，保留 English 可切。
